# FlangeConnect · WFPr-proefmodule

Statische e-learning in het Nederlands. De module bevat drie video’s en controlevragen. De browser bewaart de voortgang lokaal. De video’s hebben ingebakken ondertiteling.

GitHub Pages serveert `index.html` vanaf de hoofdbranch. De HTML bevat een robots-metatag met `noindex`. Logo en praktijkfoto komen van de officiële FlangeConnect-website. Open Sans is opgenomen onder de SIL Open Font License in `assets/brand/OFL.txt`.
